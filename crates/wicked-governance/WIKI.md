# The architecture wiki → Steering

**Moved: this guide is now [STEERING.md](./STEERING.md).**

"The architecture wiki" was the original name of the doc-ingest lane of what is now
**Steering** — the unified governance surface: one steering-rule model across seven steering
types (architecture, development, security, testing, operations, compliance, design-ux),
managed from wicked-studio's Steering section and the `wicked-core rules` CLI.

Nothing you knew is invalidated — the doc format, the `rules
ingest/fanout/relink/drift/recall/scoreboard/retire` verbs, the kill switch, and the
`wiki:`-prefixed recall scopes (live store data; the prefix is historical) all carry over.
See [STEERING.md](./STEERING.md) for the full operator guide, including what changed: the
merged rule/policy model, the seven types, the four management flows, and the two
first-class authoring lanes.
